## Global Constraints

- “Raw data is immutable.” / “Counts, not proportions.” / “No look-ahead.”
- “One component at a time”, ordem `data → reconcile → detectors → threshold → select → evaluate → stats`.
- “\|ΔAUC-PR\| ≤ 0.01 per task and the same method ranking.”
- Fonte única: `fbfa609bba6cb0b0f2a9e8d73be18022aec319b7`; 14 tarefas = PA + 13 regiões.
- MCD usa FAST-MCD C-steps próprio; `sklearn.covariance.MinCovDet` somente em testes.
- Dependências somente via `uv add`; configs TOML/frozen dataclasses; módulos ≤400 linhas.
- FAR = 1/60 por região-mês; produção usa Generator; sementes de biblioteca derivadas de SeedSequence.
- Commits locais convencionais; sem push. As condições da spec e do plano global são cumulativas.

## Review Focus

- Oráculo produz 1 tarefa ou resultados sem proveniência: tarefa 1/9 bloqueia E0.
- Região/mês ausente confundido com zero: tarefa 2 rejeita estrutura incompleta.
- Matriz singular, feature constante e dimensão de uma feature: tarefas 3/4 têm testes explícitos.
- Dados de teste alteram fit, threshold ou seleção anterior: tarefas 4/5/6 testam invariância.
- Scores empatados, rótulo único e ausência de detecção: tarefas 5/7/8 preservam status/denominador.

### Task 3: S, previsor NB2 e MinT(Shrink) — think

**Decisões:** [D2 e D5](../../protocol-decisions.md) (27/09). O MinT reconcilia previsões de contagem um passo à frente, nunca scores; o encolhimento é o de Wickramasuriya et al. (2019) com alvo diagonal e λ de Schäfer–Strimmer, não o Ledoit–Wolf do sklearn.

**Files:** Create `src/headd_l0/reconcile.py`, `tests/test_reconcile.py`, `src/headd_l0/forecast.py`, `tests/test_forecast.py`; Modify `MIGRATION.md`. `forecast.py` é justificado por dois chamadores: a reconciliação (D5) e os nulos NB2 da D-GT3 (Experimentos Task 4). statsmodels já está declarado; nenhuma dependência nova.

**Interfaces:**

- `forecast.py`: `harmonic_design(months: np.ndarray) -> np.ndarray` com colunas `1, t, sen(2πkt/12), cos(2πkt/12)` para k=1,2 (t em meses, 0 = 2009-01); `NB2Fit(coefficients: np.ndarray, alpha: np.ndarray, converged: np.ndarray, train_months: int)` congelada, eixos `[n_series,6]`, `[n_series]`, `[n_series]`; `fit_nb2(counts: np.ndarray, train_months: int = 60) -> NB2Fit` recebe o painel completo `[n_series,132]` e usa só `[:, :train_months]`; `forecast_mean(fit: NB2Fit, months: np.ndarray) -> np.ndarray` devolve μ̂ `[n_series,len(months)]`. O modelo é estático após o treino: μ̂ₜ para t ≥ 60 é a previsão um passo à frente e, para t < 60, o ajuste in-sample. Falha de convergência fica registrada em `converged`, sem modelo substituto silencioso.
- `reconcile.py`: `summing_matrix(hierarchy: Hierarchy) -> np.ndarray` `[14,13]`; `shrinkage_covariance(errors: np.ndarray) -> tuple[np.ndarray, float]` recebe erros `[n_train,14]` e devolve Ŵ e λ̂; `reconcile(base: np.ndarray, S: np.ndarray, method: str, *, covariance: np.ndarray | None = None) -> np.ndarray` com base `[14,time]` em contagens e saída coerente de mesma shape; `MinTFit(covariance: np.ndarray, shrinkage: float, train_months: int)` congelada; `fit_mint(observed: np.ndarray, fitted: np.ndarray, train_months: int = 60) -> MinTFit`; `reconciled_residuals(observed: np.ndarray, fitted: np.ndarray, S: np.ndarray, fit: MinTFit) -> np.ndarray` = y − P·μ̂; `standardize(residuals: np.ndarray, train_months: int = 60) -> np.ndarray` divide cada série pelo desvio-padrão de treino (ddof=1). `RECONCILERS` contém bottom_up/mint_shrink. Linhas na ordem PA + 13 folhas; `observed = S @ counts`.
