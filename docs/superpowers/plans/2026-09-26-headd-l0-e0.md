# HEADD-Series L0 Baseline and E0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extrair componentes mínimos do CDADE e verificar, sem forçar equivalência, se B1 satisfaz E0 nas 14 tarefas SIVEP.

**Architecture:** Funções numéricas no pacote plano; oráculo original exportado pelo SHA em ambiente separado. Correções metodológicas são registradas e condicionam o gate, sem contaminar produção com um modo legado. A ordem de porte permanece data, reconcile, detectors, threshold, select, evaluate, stats.

**Tech Stack:** Python ≥3.12, uv, numpy, pandas, scipy, PyOD, river, scikit-learn, pyarrow, pytest, ruff.

**Spec:** [Arquitetura §§1–7 e 9–10](../specs/2026-09-26-headd-l0-architecture.md); [plano global](2026-09-26-headd-l0-global.md).

## Global Constraints

- “Raw data is immutable.” / “Counts, not proportions.” / “No look-ahead.”
- “One component at a time”, ordem `data → reconcile → detectors → threshold → select → evaluate → stats`.
- “|ΔAUC-PR| ≤ 0.01 per task and the same method ranking.”
- Fonte única: `fbfa609bba6cb0b0f2a9e8d73be18022aec319b7`; 14 tarefas = PA + 13 regiões.
- MCD usa FAST-MCD C-steps próprio; `sklearn.covariance.MinCovDet` somente em testes.
- Dependências somente via `uv add`; configs TOML/frozen dataclasses; módulos ≤400 linhas.
- FAR = 1/60 por região-mês; produção usa Generator; sementes de biblioteca derivadas de SeedSequence.
- Commits locais convencionais; sem push. As condições da spec e do plano global são cumulativas.

## Review Focus

- Oráculo produz 1 tarefa ou resultados sem proveniência: tarefa 1/9 bloqueia E0.
- Região/mês ausente confundido com zero: tarefa 2 rejeita estrutura incompleta.
- Matriz singular, feature constante e dimensão de uma feature: tarefas 3/4 têm testes explícitos.
- Dados de teste alteram fit, threshold ou seleção anterior: tarefas 4/5/6 testam invariância.
- Scores empatados, rótulo único e ausência de detecção: tarefas 5/7/8 preservam status/denominador.

Arquivos de produção: `src/headd_l0/{__init__,data,reconcile,detectors,threshold,select,evaluate,stats,inject,run}.py`; cada um entra apenas na tarefa dona. Testes espelham módulos, mais `tests/test_reference.py`. `tests/conftest.py` define fixtures pequenas; dados de referência em `tests/reference/<component>.npz` e `manifest.json`. Cada tarefa executa seu teste vermelho antes da implementação e, ao final, `uv run ruff check .`, `uv run ruff format --check .`, `uv run pytest`. Os exemplos são a âncora mínima; acrescentar os casos nomeados no mesmo passo.
